---

SQLite's FTS5 module gives a docs site real search with no search service.
Using `content=''` makes it an *external content* index: it stores the terms but
not a second copy of the text, so the file stays small and the index cannot
disagree with the `posts` table.

```sql
create virtual table posts_fts using fts5 (
    title, summary, text, content = '', tokenize = 'porter unicode61'
);
```

The `porter` tokenizer stems, so a search for *deploys* finds *deploying*.
